Логика: найти компании, которым нужен сайт/лендинг/бот, а не ждать заказ в очередь.
Скрипты: `probe_cold*.py`, `probe_overpass*.py` (запуск `py -3 <имя>`).

## Годные

| Источник | Что даёт | Статус |
|---|---|---|
| **2GIS API** (`catalog.api.2gis.com/3.0/items`) | Фильтр `has_site` (true/false) → организации с сайтом или БЕЗ; города РФ + Минск, структурированный JSON | ✅ работает (2026-11-16): демо-ключ, 571 лид собран; подробности ниже |
| **Google Places API** (Text Search + Place Details) | `websiteUri`, телефоны, глобально | ⏳ ключ Stas'а отвергнут (`REQUEST_DENIED` — API не включён в консоли Google Cloud). Включить Places API → free quota. Риск: геоблок Google, как у Gemini |
| **Yandex Maps** (рендер в браузере) | Орг-карточки, сайт, телефон | 🟡 HTML-страница отдаётся (200, 1.9М), но ссылки /org/N грузятся JS — нужен браузерный рендер (in-app browser). Медленно, точечно, не для пачек |

| Источник | Почему |
|---|---|
| `firmy.ru` | SSL handshake failure |
| `yell.ru` | таймаут |
| `blizko.ru` | 403 |
| `zoon.ru` / `gomel.zoon.ru` | корень живой, но секции и карточки — SPA (шаблоны `${item.url}`, ссылок на организации в HTML нет); резвиться не стоит |

| `2gis.by` HTML | живой, но SPA; данные — только через API |

## Статус 2026-11-16: ключ есть, коллектор работает

- **Ключ:** демо `client-search-leads` (в `hunter/.env` → `GIS_API_KEY`), действует до **16.12.2026**,
  квота Places API 1000 запросов/мес (счётчик в `cold_leads.py` стопится на 900).
- **Коллектор:** `hunter/cold_leads.py [N на связку]` → `tracker/leads.json`.
  Первый прогон: **571 лид без сайта** (10 городов × 20 ниш, 200 запросов).
- **Ограничения демо/данных (проверено вживую):**
  - из РБ отдаётся **только Минск** (Гомель/Витебск/Могилёв/Гродно/Бобруиск → 404);
  - `page_size` максимум **10** (20+ → 400), `page` работает, `q` обязателен;
  - `fields=items.contact_groups` (телефон/почта/сайт) **молча игнорируется** — доступ
    только по доп. разрешению (через отдел продаж). Бесплатно: имя, адрес, рубрики, расписание;
  - ответ не содержит URL сайта — для `has_site=true` лидов сайт ищем вручную.
